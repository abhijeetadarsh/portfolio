Jul 2025 — present · Bengaluru

Service 01

Agent orchestration

LangGraph workflows behind a manager agent, with a critique-and-reflect loop that scores every draft answer and re-drafts the weak ones.

Its request planner maps a natural-language ask to an ordered sequence of internal REST calls, generates the payloads, and executes them against live company systems — so the assistant reaches past static documents.

Service 02

Hybrid retrieval

Fuses vector and graph retrieval with cross-encoder re-ranking and chunk balancing.

The whole retrieval path is config-driven — vector-to-graph mix, re-ranking, chunk budgets — so onboarding a new use case is a config change rather than a code change.

The maths half of the degree is why this work is defensible rather than copied: numerical methods, linear algebra and graph theory are what a re-ranker is actually made of.

testing-framework

Python · Kubernetes · SSH

  • private

An API test harness that attributes Kubernetes pod logs to the individual request that produced them — it bookmarks a --tail=0 stream per pod over SSH and slices the window per request. Built because “which of these 200 concurrent requests wrote that traceback?” had no good answer.

ugc-studio

FastAPI · microservices · Playwright · MCP

  • private
  • demo soon

URL → asset-kit orchestrator. A provider layer routes each task to whichever model backend suits it, with per-input-type pipeline stages and MCP as an alternative transport — the same shape as an LLM gateway.

arch-setup

Python · Bash · i3

An Arch Linux installer split into a system layer — partitions, filesystems, kernel, bootloader; hard, risky, done once — and a user layer of packages and stowed dotfiles you re-run forever. The README argues the split rather than just shipping it.
